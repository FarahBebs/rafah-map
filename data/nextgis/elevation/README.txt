Elevation data for your GIS    
===========================    

## About    

Get elevation data in a convenient format using data.nextgis.com   

Source:    
   * Digital Surface Model "Copernicus WorldDEM-30"    


## Contents    

Depending on the order, the dataset may contain the following types of data:    

   * Elevation contours (contour_lines)    
   * Digital elevation model (dem.tif)    
   * Hillshade (hillshade.tif)    
   * Ready-made project file for your GIS (only for QGIS, ArcGIS Pro and ArcMap formats)    
   * Order boundary (order_boundary.geojson)
