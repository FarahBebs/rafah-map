Building footprints data for your GIS    
=====================================    

## About    

Get building footprints data in convenient format using https://data.nextgis.com   

Source:    
   * Microsoft – The Building Footprints dataset provides global coverage using AI to extract building outlines from Bing Maps aerial imagery.   
   * Google – The Open Buildings dataset contains building footprints derived from high-resolution satellite imagery, primarily across regions of the Global South.   
   * OpenStreetMap (https://osm.org) – database of open spatial data and a community of mappers who keep it up-to-date.   


## Contents    

Each dataset contains the following data layers:   
   * Building footprints — Microsoft (building-polygon-ms)   
   * Building footprints — OpenStreetMap basemap (polygons) (building-polygon)   
   * Building footprints — OpenStreetMap basemap (points) (building-point)   
   * Building footprints — Google Open Buildings (points) (building-point-gg)   
   * Building footprints — Google Open Buildings (polygons) (building-polygon-gg)
